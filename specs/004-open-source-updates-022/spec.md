# Typst Studio 0.2.2：同目录 PDF、公开源码与后台更新

状态：已确认。现有源码仓库保留全部历史转公开，自有源码采用MIT。2026-10-18。
目标是 Typst Studio 软件项目；EMDoc_demo仅作为本地验证输入，不上传其文档和图片。

## 需求与业务规则

### PDF 输出

- 对已保存路径的编译入口，每次成功编译（显式或自动）在同目录写入同名PDF。`main.typ → main.pdf`，`chapters/demo.typ → chapters/demo.pdf`。
- 输出跟随固定的编译入口，不能因PDF反向定位或普通文件切换写成子文件PDF；只有显式编译当前文件才改变入口。
- PDF反映本次编译的缓冲区内容，包括未保存编辑；不因此保存或覆盖`.typ`源码。未命名文档没有确定输出路径，只预览并提示先保存源文件。
- 新结果通过后台临时文件与原子替换发布；相同字节不重复写。串行/合并写入确保较旧任务不覆盖较新产物。
- 同名PDF是本入口的构建产物，会更新覆盖。失败、取消或过期编译不覆盖上次成功PDF；不跟随PDF符号链接写到工程外，不替换目录。
- 目标不可写、文件被占用、磁盘不足等应显示非阻塞提示，保留当前预览和旧文件；不能把写入失败当作已生成磁盘PDF。
- 写入自己的PDF不触发文件监听编译循环。

### 更新

- 两端首个窗口可操作后默认检查一次更新；设置可关闭启动检查，并提供手动检查。
- 新版本后台下载和验证，使用原生进度/状态提示，编辑、滚动和编译继续可用。失败、离线、取消不会阻塞或退出软件。
- 下载完成提示“安装并重启”；用户点击后先处理所有未保存文件。取消保存、保存失败或外部冲突时不启动安装。
- Mac沿用Sparkle；Windows采用NetSparkle核心与WinUI原生界面，复用现有Inno安装器。无WPF/Avalonia界面，不引入跨平台UI层。
- Windows使用独立ARM64/x64签名更新源，按安装进程架构匹配。禁止错误平台/架构、旧版本、损坏签名进入安装。
- 安装器只在获准退出后运行；不强杀编辑进程，成功后由单一负责方启动一次新版本。安装失败保留日志，不宣称已成功或自动回滚。
- 密钥保留本机安全存储，源码与Release只包含公钥、签名、公开元数据和产物。

## 验收标准

| ID | 验收 |
| --- | --- |
| PDF01 | 两端main及嵌套入口在自己的目录生成同名PDF，字节与成功编译结果一致；默认原色，不应用夜间/绿色阅读滤镜。 |
| PDF02 | 自动编辑更新PDF，切换/逆向定位不写子文件PDF；未保存源码磁盘字节保持不变。 |
| PDF03 | 失败/取消/过期/并发结果不破坏旧PDF；不可写/被占用显示明确提示；不跟随符号链接/目录，不产生监听循环。 |
| UPD01 | 启动仅检查一次，可关闭、可手动检查；离线/超时/无新版本/取消下载不妨碍编辑。 |
| UPD02 | 正确数值版本与平台/架构筛选，损坏签名/包/清单、缺资产和降级均拒绝安装。 |
| UPD03 | 真实下载进度、校验和状态；UI线程不执行下载/大文件哈希；后台任务期间实际编辑和预览响应。 |
| UPD04 | 在隔离旧安装上测试更新：未保存内容可保存/取消，失败不退出；安装成功只重启一次，失败可诊断。 |
| DOC01 | README链接、平台差异、构建步骤与实际0.2.2一致；至少各3张真实截图，无个人文档信息。 |
| OSS01 | 有明确许可证、第三方声明；公开范围经确认，凭据检查完成；GitHub源码可公开访问。 |
| REL01 | 三个本地产物、版本/架构、签名/摘要、公开Release及两端更新源相互一致，无Actions运行。 |
