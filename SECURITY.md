# Security

Use GitHub private vulnerability reporting on this repository's **Security** tab for sensitive reports. Do not put private documents, credentials, signing keys, or exploit details into public issues.

Please include the app version, OS/architecture, a minimal reproduction, and the expected security boundary. Current work focuses on the latest released version; there is no guaranteed response SLA.

Updates are signed and verified with public keys embedded in the applications. Private keys are not stored in this repository or GitHub Actions. Download applications only from this repository's Releases.
