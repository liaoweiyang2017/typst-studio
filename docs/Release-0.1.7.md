# Typst Studio 0.1.7

- 接入 Sparkle 后台更新。应用内下载、校验和准备更新，完成后显示“重启并更新”；不需要手动打开 DMG 拖拽覆盖。
- 下载和准备期间可继续编辑、编译、阅读 PDF。未保存文档会在启动重启流程前提示保存，取消后继续工作。
- 更新包使用 Ed25519 签名，私钥保存在开发机器钥匙串；公开发布流水线验证签名和 SHA-256。
- 新增双向文字定位：源码选区或当前行 → PDF（⇧⌘J），PDF 选中文字 → 源码（⌥⌘J）。支持右键菜单、工具栏和 ⌘ 点击文本行。
- 逆向定位可查找项目中其他 .typ 源文件。后台搜索处理换行、空白及常见连字，PDF 文本索引按编译结果缓存；重复文字提示扩大选区，不随意跳转。

定位使用文本匹配，尚不是编译器级源映射。公式、宏生成内容以及重复文字不保证精确定位；跨文件跳转后按现有规则显示所打开源文件的预览。Qt 迁移仅完成调研，本版保持 Swift 原生实现。

Apple Silicon arm64，macOS 14 或更新版本，内置 Typst 0.15.1。安装包使用 ad-hoc 签名，尚未进行 Apple 公证。

0.1.6 及更早版本仍使用旧下载方式，需要手动安装一次 0.1.7；从 0.1.7 开始支持应用内后台更新。
