# Typst Studio 0.1.8

- 使用 Tinymist 的编译源码 span 与页面坐标实现双向定位，替换文字搜索。支持数学标识符、相同公式出现在不同文件、中文位置转换及旋转内容。
- 保持 SwiftUI/AppKit 编辑界面与 PDFKit 原生 PDF 预览，PDF 导出和定位共享同一个增量编译进程。
- 从 PDF 跳到被引用文件时保留主文档预览；未保存的被引用文件修改也会编译到主文档，无需改写磁盘源文件。
- 在源码中使用 ⇧⌘J；在 PDF 中选择文字后使用 ⌥⌘J，或按住 ⌘ 点击可见文字/公式字形。工具栏和右键菜单继续可用。
- 内置 Tinymist 0.15.10（Typst 0.15.1，带小范围源码映射补丁），首次运行不下载编译器。
- macOS 编译依赖监听改用有界范围的文件轮询，修复依赖变化后缓存未刷新的问题。

未渲染的代码或没有编译器 span 的图形不会被猜测定位。同一宏源位置生成多个输出时，优先选择靠近当前阅读页的位置；项目外部包源码只提示来源，不自动打开编辑。

Windows / WinUI 3 迁移已完成独立分析，本版没有开始 Windows 实现。

Apple Silicon arm64，macOS 14 或更新版本。支持从 0.1.7 在应用内后台更新。安装包为 ad-hoc 签名，尚未 Apple 公证；更新归档另有 Ed25519 签名校验。
