# Typst Studio 0.2.1

- Mac 与 Windows 增加原生编译按钮。按钮、菜单和现有快捷键（Mac ⌘B / Windows Ctrl+B）编译当前正在编辑的文件，并将它设为新的预览入口。
- 普通文件切换、搜索/错误跳转和 PDF 反向定位只切换编辑位置，不再自动改换 PDF 或编译入口。
- 编辑后仍自动更新固定预览入口；Windows 尊重已有自动编译设置。编译包含文件的修改时继续使用完整主文档，不静默写入磁盘。
- 处理快速切换入口、尚未完成的编辑编译、旧结果晚到与错误恢复；失败保留上次成功预览，禁止使用过期定位。
- Windows 复用 Tinymist 进程和源文件缓存，切换入口时重建定位任务；Mac 保留入口缓存与 PDF 阅读位置。
- 完善两端编译错误显示，兼容诊断通知稍晚到达的情况。

Windows ARM64/x64，macOS ARM64；编译器随安装包内置，均在本地构建。源代码保存在私人仓库。macOS 更新通过现有 Sparkle 签名验证，发布校验在本地执行，不运行 GitHub Actions。

验证覆盖真实编译器、公式/中文/跨文件定位、导航不编译、包含文件编辑、入口切换、快速连续请求、失败旧预览、撤销和文件冲突。Windows x64 在 ARM Windows 虚拟机中运行，不等同于实体 x64 机器验证。Windows 未进行 Authenticode 签名；Mac 使用 ad-hoc 签名，未做 Developer ID 公证。
