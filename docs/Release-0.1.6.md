# Typst Studio 0.1.6

- 设置支持“跟随系统 / 简体中文 / English”，即时切换设置、欢迎页和主要操作菜单的文字。
- 设置按通用、编辑器、PDF 预览、软件更新分组，采用原生 SwiftUI 侧栏和分组表单。
- 浅色、深色外观下的 PDF 配色集中管理，保留独立的夜间与绿色阅读模式。
- 拼写检查、打字音效、预览跟随光标的偏好现在会持久保存。
- 字体列表仅在打开设置时加载；未打开文档时禁止插入字体指令。

Apple Silicon arm64，macOS 14 或更新版本，内置 Typst 编译器。
